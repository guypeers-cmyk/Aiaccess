WAT ER NIET IN ZIT
Er staat geen naam, geen leeftijd, geen ziekte en geen diagnose in deze set. Het profiel is een
leeg sjabloon. Wat jij invult, blijft van jou: de set werkt lokaal en stuurt niets door.

EEN VERZOEK, GEEN VOORWAARDE
Gebruik je deze set voor mensen met een beperking? Laat hen zelf meestesten. Een antwoord dat
niet toegankelijk is, is fout — ook als het inhoudelijk juist is. Dat is de regel waar alles
in deze set uit volgt.
